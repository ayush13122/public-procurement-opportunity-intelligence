# Phase: Exploratory Data Analysis (EDA)

## Purpose
Run a reproducible analysis of the cleaned Assam historical procurement extract. The script produces auditable CSV tables, interactive HTML charts, and a Markdown summary. It does not alter source or cleaned data.

## Command
From the project root:

```powershell
python src/run_procurement_eda.py
```

## Input
- `data/processed/assam_procurement_cleaned.csv`
- Optional: `reports/assam_record_niche_assignments.csv` generated by `python src/profile_procurement_categories.py`

## Main questions
1. How many records and unique buyer organizations are present?
2. What is the record distribution across original broad categories and detailed classifications?
3. How many tender values are missing, zero, or positive; what is the positive-value distribution by category?
4. How do record counts vary across fiscal years and published months?
5. Which buyer organizations publish the most records in this extract?
6. Which tender stages and procurement methods are recorded?
7. Which candidate analytical niches have the most records, and how many records still need manual review?
8. Which fields have poor coverage and therefore limit downstream conclusions?

## Outputs
All output files are written under `reports/eda/`; charts are under `reports/eda/charts/`.

## Interpretation guardrails
- Historical Assam patterns are not automatically representative of all Indian procurement.
- `tender/value/amount` is tender value, not profit or guaranteed revenue.
- Zero and missing tender values are distinct; neither is silently imputed.
- Niche mappings are rule-based candidates and require review, particularly for ambiguous labels.
- Current-tender recommendations require a separate current-data snapshot and its own freshness/provenance metadata.
