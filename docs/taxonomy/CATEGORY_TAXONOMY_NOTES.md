# Category Profiling & Niche Taxonomy — Notes

## What was profiled
- Source: Assam Public Procurement Data archive from data.gov.in.
- Fiscal-year files: 2016–2017 through 2021–2022.
- Total rows: 34,232.
- Original source columns: 34.
- Original broad procurement categories: 3 (`Works`, `Goods`, `Services`).
- Original detailed classification labels: 89.

## Why we need an analytical niche layer
We will preserve the original fields exactly and add a separate *suggested_analytical_niche* field. This gives the app friendlier cross-category navigation without pretending the source itself contains all of these niche groups.

## Rules
1. Keep `tender/mainProcurementCategory` and `tenderclassification/description` unchanged.
2. Use the generated `assam_niche_mapping_review.csv` as a review worksheet, not as unquestioned ground truth.
3. Rows marked `PROVISIONAL` receive a first-pass category suggestion from the source classification text. Check them using the sample tender titles.
4. Rows marked `REVIEW` must not be automatically treated as a confirmed niche. Inspect the tender title or detailed record before finalizing the mapping.
5. `Supply of Materials` is intentionally marked for review because the label does not reveal which materials are being procured.
6. Original Assam historical data and current national tender records must remain separately identifiable. A shared niche taxonomy can link them, but we must not erase geographic or time-period differences.

## Files generated by the profiling script
- `reports/assam_broad_category_profile.csv`: counts by the original top-level category.
- `reports/assam_classification_by_broad_category.csv`: detailed original classifications cross-tabulated by broad category.
- `reports/assam_niche_mapping_review.csv`: count, proposed analytical niche, mapping rationale and sample titles for all 89 labels.
- `reports/assam_field_coverage_by_category.csv`: availability of important fields for each broad category.
- `reports/assam_year_profile.csv`: record and key-field coverage by fiscal year.
- `reports/assam_category_profiling_summary.md`: concise human-readable summary.

## Current interpretation
The dataset is highly concentrated in `Works`, particularly civil-work classifications. It is useful for a broad procurement market explorer, but conclusions must reflect this category concentration. The labels mapped to a niche are only first-pass suggestions; the taxonomy should be reviewed before it powers company-facing recommendations.
